# Libft

## Description

Libft is a personal C library implementing commonly used functions from the
standard C library, together with additional string, memory, character,
conversion, file-descriptor output, and linked-list utilities. The project is
part of the 42 curriculum and is designed to provide a reusable foundation for
later C projects while reinforcing pointers, dynamic allocation, error
handling, and data structures.

The compiled library is `libft.a`. It is built from the project sources with
the compiler warnings required by the 42 coding standards.

## Library contents

### Character classification and conversion

- `ft_isalpha`, `ft_isdigit`, `ft_isalnum`, `ft_isascii`, and `ft_isprint`
  classify characters.
- `ft_toupper` and `ft_tolower` convert alphabetic characters.

### Strings

- `ft_strlen` returns a string length.
- `ft_strchr` and `ft_strrchr` search for a character.
- `ft_strncmp` compares at most `n` characters.
- `ft_strnstr` searches for a substring within a bounded string.
- `ft_strdup` duplicates a string.
- `ft_strlcpy` and `ft_strlcat` provide bounded copying and concatenation.
- `ft_substr` extracts a substring.
- `ft_strjoin` concatenates two strings.
- `ft_strtrim` removes characters from both ends of a string.
- `ft_split` splits a string using a delimiter.
- `ft_strmapi` and `ft_striteri` apply a function to each character.

### Memory and conversion

- `ft_memset`, `ft_bzero`, `ft_memcpy`, and `ft_memmove` manipulate memory.
- `ft_memchr` searches memory and `ft_memcmp` compares memory blocks.
- `ft_calloc` allocates zero-initialized memory with overflow-aware sizing.
- `ft_atoi` converts a string to an integer.
- `ft_itoa` converts an integer to a newly allocated string.

### File-descriptor output

- `ft_putchar_fd`, `ft_putstr_fd`, `ft_putendl_fd`, and `ft_putnbr_fd`
  write characters, strings, lines, and numbers to a file descriptor.

### Linked lists

The library defines the following singly linked-list node type:

```c
typedef struct s_list
{
    void            *content;
    struct s_list   *next;
}   t_list;
```

The list API includes `ft_lstnew`, `ft_lstadd_front`, `ft_lstadd_back`,
`ft_lstsize`, `ft_lstlast`, `ft_lstdelone`, `ft_lstclear`, `ft_lstiter`, and
`ft_lstmap`. List functions operate on generic `void *` content and accept
caller-provided callbacks where content must be deleted, transformed, or
visited.

## Instructions

### Compilation

From the repository root, build the static library with:

```sh
make
```

This compiles the source files with `cc -Wall -Wextra -Werror` and creates
`libft.a`. To remove object files, run `make clean`; to remove all generated
files, run `make fclean`; to rebuild from scratch, run `make re`.

### Using the library

Include the public header and link the archive when compiling a C program:

```c
#include "libft.h"
```

```sh
cc -Wall -Wextra -Werror -I. main.c libft.a -o my_program
./my_program
```

The project does not provide an executable by itself; it provides functions
for inclusion and linking in other C programs.
